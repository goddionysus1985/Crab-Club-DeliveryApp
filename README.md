# 🦀 CRAB CLUB — Преміум ресторан & Доставка

Сучасний, розкішний, високоефективний веб-додаток для замовлення їжі та доставки ресторану **CRAB CLUB** (смт. Овідіополь).

🔗 **GitHub Pages URL**: `https://goddionysus1985.github.io/Crab-Club-DeliveryApp/`

---

## 🌟 Особливості та функціонал

- **💎 Преміальний дизайн**: Dark Obsidian (#0B0B0F) з золотисто-рубіновими акцентами, матове скло (Glassmorphism), плавні анімації.
- **🍣 208 реальних позицій меню**: Сети, роли, піца на дровах, пасти, wok, бургери, сніданки, десерти та напої з оригінальними фото Poster POS CDN.
- **🔍 Живий пошук & фільтри**: Пошук страв та інгредієнтів (`⌘K / Ctrl+K`), фільтри за смаками (*Хіти, Шеф-вибір, Гостре, Веган*).
- **🛒 Розумний кошик**: Прогрес-бар безкоштовної доставки, система промокодів, перемикач самовивозу зі знижкою 10%.
- **🚀 Зручний чекаут**: Вибір населених пунктів, часу доставки, способів оплати (Apple Pay, онлайн, термінал, готівка).
- **⏱️ Живий трекер замовлення**: 4 етапи приготування та доставки зі зворотним відліком часу.
- **📍 Зони доставки, FAQ, відгуки та контакти**: Інтерактивна таблиця зон, відгуки гостей та швидкий зв'язок у месенджерах.

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide Icons**
- **Canvas Confetti**

## 💻 Локальний запуск

```bash
# Встановлення залежностей
npm install

# Запуск dev сервера
npm run dev

# Збірка для production
npm run build

# Попередній перегляд production збірки
npm run preview
```
